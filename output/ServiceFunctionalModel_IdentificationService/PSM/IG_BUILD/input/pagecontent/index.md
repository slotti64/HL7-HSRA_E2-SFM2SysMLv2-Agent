# HL7 Identification Service FHIR R5 Implementation Guide

This Implementation Guide is generated automatically by the **SFM2FHIR-PSM** pipeline from the HSRA E2 Identification Service Service Functional Model and its derived SysML v2 PIM.

It declares the FHIR R5 resources, profiles, extensions, operations, subscription topics, value sets, code systems, naming systems, and a CapabilityStatement that together specify the Identification Service.

## Contents

- **Profiles** — FHIR R5 StructureDefinitions for each PIM data class
- **Extensions** — Custom extensions for attributes not covered by base resources
- **Operations** — Patient `$merge`, `$unmerge`, `$everything`, `$match`
- **SubscriptionTopics** — Identity update notification topic
- **Terminology** — ValueSets, CodeSystems, NamingSystems
- **CapabilityStatement** — Service capability declaration
- **Examples** — Reference instances for each profile
